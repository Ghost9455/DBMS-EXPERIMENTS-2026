# Experiment 03 — Employee, Department and Project Queries

## Aim
Create an Employee–Department–Project database schema, insert at least 30 employees across 5 departments and 8 projects, and execute SQL queries demonstrating selection, projection, aggregate functions, GROUP BY, HAVING, CASE expressions, and ORDER BY.

## Concepts Covered
- Creating tables with primary and foreign keys
- Inserting employee, department, and project records
- Selection and projection
- Aggregate functions: COUNT, AVG, MAX, MIN, SUM
- GROUP BY and HAVING
- CASE expressions
- Sorting using ORDER BY
- Department-wise and project-wise summaries

## SQL File
`experiment_03.sql`

## How to Run
1. Open `experiment_03.sql` in MySQL Workbench.
2. Execute the SQL statements in order.
3. Review the result grid for each query.

## Expected Output
The queries display employee records, filtered employee lists, salary statistics, department-wise employee counts and averages, salary categories, and project-wise employee counts.

## Requirements
- MySQL 8.0+ recommended.
- The script drops and recreates the Employee, Project, and Department tables. Run it in a test database.
