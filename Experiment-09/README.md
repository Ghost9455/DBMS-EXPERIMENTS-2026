# Experiment 9: Query Performance and Indexing

## Aim

To analyze SQL query performance before and after applying indexes.

## Concepts Covered

* Railway Booking Dataset
* Query Performance
* Database Indexing
* EXPLAIN
* EXPLAIN ANALYZE
* Query Execution Plans

## Theory

An index is a database structure that helps retrieve records efficiently without scanning every row of a table in suitable queries.

Query execution plans help analyze how a database executes a query.

### EXPLAIN

EXPLAIN displays the execution plan selected by the database.

### EXPLAIN ANALYZE

Where supported, EXPLAIN ANALYZE executes the query and reports actual execution information.

## Dataset

The experiment uses a railway booking dataset containing approximately 5,000 records.

## Expected Output

Query execution plans and performance measurements are compared before and after indexing.

Actual execution times may vary depending on the database system, hardware, and dataset.

Refer to the Experiment 9 Expected Outputs PDF in the `Expected-Outputs` folder.

## Result

The effect of indexing on query execution and database performance is studied.
