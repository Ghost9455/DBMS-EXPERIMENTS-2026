# Experiment 10: SQL Query Optimization

## Aim

To identify and optimize slow SQL queries using indexing and query rewriting.

## Concepts Covered

* Customer Orders Dataset
* Query Optimization
* Database Indexing
* Query Rewriting
* Query Execution Plans
* Performance Comparison

## Theory

SQL query optimization improves query execution efficiency by choosing appropriate ways to retrieve and process data.

### Indexing

Indexes can improve data retrieval for suitable queries.

### Query Rewriting

Query rewriting changes the structure of a query while preserving its intended result.

### Performance Analysis

Query execution plans and execution times can be used to compare query performance before and after optimization.

## Dataset

The experiment uses a customer orders dataset containing approximately 10,000 records.

## Expected Output

Five slow queries are analyzed and optimized. Their execution plans and performance are compared.

Actual performance improvements depend on the database system, indexes, data distribution, and query structure.

Refer to the Experiment 10 Expected Outputs PDF in the `Expected-Outputs` folder.

## Result

SQL query optimization techniques are studied to improve database query performance.
