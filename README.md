# 📚 DBMS-EXPERIMENTS-2026

### Database Management Systems Laboratory Practicals using MySQL

This repository contains SQL source codes for DBMS laboratory experiments.
It covers database design, relational schemas, SQL queries, views,
recursive queries, stored procedures, triggers, and database constraints.

The objective is to understand and implement fundamental and advanced
Database Management System concepts using MySQL.
